❓ 使用说明

    
快速上手

    
    
      
  • 点「📂 导入PDF」选真题（或把 PDF 拖进窗口）。
    • 
      
  • 🔍 查词：轻点单词弹释义；若相邻词能组成词组，弹窗顶部出现「词组」候选，点一下直接查词组；划选词组或整句可翻译；点「＋生词本」保存。
    • 
      
  • ✒️ 书写 / 🖍 荧光 / 🧽 橡皮：用 Apple Pencil 或鼠标在页面上写画、划重点、擦除。
    • 
      
  • 🈶 句译（句子翻译）：点亮它后，在 ✒️ 书写 模式下轻点句子就能整句翻译（原文会临时黄底高亮），不用再切回 🔍 模式；照常写字不受影响——手一动（超过约 7px）就立刻变回书写，抬手没动到才翻译。关掉它就回到完全正常的书写模式。
    • 
      
  • ✒️ 书写的三种笔：切到 ✒️ 书写后，颜色圆点右边会出现 ✎ 自由 / ／ 直线 / ～ 波浪 三个选项——直线按住一拖就是笔直的直线，波浪会画标准的波浪线（常用来划"这句翻译得不对"之类的标记）。
    • 
      
  • 画完停一停 → 自动生成规则图形：自由书写模式下画一笔，画完笔尖不要抬起来、在原地停住约 0.7 秒，这条笔迹就会自动变成规则的直线 / 圆形 / 矩形 / 三角形。生成后四周出现蓝色控制点，拖动任意一个角就能自由放大缩小；不想用了 Ctrl+Z 撤销或用 🧽 橡皮擦掉。识别只在"笔尖不离开屏幕"时触发：把笔尖留在原地停住才会成形，一抬笔就当作放弃、照原样保留（不会自动转换）。iPad 提示：笔尖停在屏上时手部轻微抖动不会打断识别（轻微抖动不算"动了"）。
    • 
      
  • ⬚ 框选（移动/缩放/删除一大片笔迹）：切到这个工具后，在页面上随手画一个圈（任意形状，不用画得很准也不用封口——抬笔时首尾自动连上），圈住的笔迹会整组被选中（淡蓝光晕 + 蓝色虚线框）。之后：拖动框内任意位置=整组移动，拖四个角上的小方块=整组等比放大缩小，Delete=删除，Esc 或圈外轻点=取消选中。全部都能 Ctrl+Z 撤销。
    
      判定原则：整条笔迹都在圈内才算选中，一条都没完整包住时就退化成"碰到就算"。想精确一点就先放大页面再圈。
    • 
      
  • 用圈圈选中（套索）：页面上只要已经有闭合的圈——圆形、椭圆、不规则的圈（包括用上面"停一停"自动生成的圆/矩形/三角），在 ✒️ 书写 或 ⬚ 框选 模式下长按这个圈约 0.5 秒（按住别动），圈里的笔迹就会被整组选中，这个圈自己会消失（相当于"圈起来→打包"）。只有明显比字母大的圈（长边约 60px 以上，约两个字母高）才触发套索——手写单词时 o / e / b / d 这些字母的小圈不会误触发，可以放心连着写。消失的圈 Ctrl+Z 能恢复；圈里什么都没有时不做事，不会白丢一个圈。判定原则：整条笔迹都在圈内才算选中，一条都没有时退化成"碰到就算"。
    
      注意：在已经被圈住的区域里写字，落笔后半秒内就要运笔，否则会被判成长按（真触发了 Ctrl+Z 就回来了）。
    • 
      
  • ⬇️ 导出PDF：笔迹（含刚生成的规则图形，导出的也是矢量线条）每页右侧页边会标出该页保存的生词，文末自动附上整份「生词表」（含释义和页码）。生词本可单独导出 JSON / CSV。
    • 
      
  • 🎯 生词自测：生词本面板点「🎯 自测」，遮住释义回忆，会/不会二选一，不会的词循环重现，当场背一遍。
    • 
      
  • 🔑 标答案与判分：查词模式轻点正文里的题号（带蓝色虚线，如 21.）弹出 A/B/C/D 标你的答案；点工具栏 🔑 粘贴参考答案（21.B 这种格式）即可自动判分、列错题。
    • 
      
  • 🙈 隐藏笔迹：对答案时点它看"干净的卷子"，再点恢复。
    • 
      
  • ⏱ 秒表：点一下开始计时，屏幕角落出现悬浮小窗（▶/⏸ 暂停继续、复位归零、✕ 收起——收起后计时继续，长按小窗可拖到顺手的位置）。刷新页面计时也不丢。
    • 
    

    
Apple Pencil 手势（iPad）

    
    
      
  • 切换橡皮的三种方式：① 笔尖在屏幕上快速轻点两下（要快、位置要近）；② 右下角悬浮 ✒️/🧽 按钮点一下即可来回切（长按可拖到顺手的位置，最可靠）；③ 顶部工具栏 🧽。
    • 
      
  • 不想用"双击切橡皮"可以关掉：点右上角 ⋯ 菜单 → 双击切换橡皮擦，勾掉即可（前面那个 ✔ 会变成 ✕）。关掉之后笔尖/鼠标双击就只是普通书写，不会因为写太快误切到橡皮；要换橡皮用右下角悬浮按钮或工具条 🧽。这个选择会被记住。
    • 
      
  • 书写时不会再弹出"拷贝 / 翻译 / 共享"：只要不是 🔍 查词模式，长按页面就不会唤起系统的选中气泡、也选不中正文（查词模式的划选翻译不受影响）。万一还想用系统那份：右上角 ⋯ 菜单 → 书写时禁用长按选中，勾掉即可。
    • 
      
  • 为什么笔杆"轻点两下"没用？那是 iPadOS 转发给原生 App 的手势（PencilKit / UIPencilInteraction），Safari 不把它转发给网页，系统设置里怎么配对网页都无效——所以请用上面②号悬浮按钮。
    • 
      
  • 双指轻点屏幕：撤销上一步；双指拖动：滚动页面；双指张合：缩放页面（放大后拖动可平移，点缩放标签「适宽/百分比」一键恢复适应宽度）。
    • 
      
  • 缩放也可用工具栏 －/＋（每档 ×1.25），桌面端 Ctrl+滚轮 / 触控板捏合同样有效。
    • 
      
  • 写字时手掌搭在屏幕上不会误画：检测到铅笔时会自动忽略手指。
    • 
      
  • 查词请切到 🔍 模式再轻点；书写模式下手指不动作，防止误触。
    • 
    

    
查词与翻译

    
    
      
  • 中文释义来自网络翻译服务（MyMemory / Google 词典），英语释义与音标来自 Free Dictionary API，需要联网。
    • 
      
  • 查不到的词：弹窗里点「✎ 手动」自己填释义，一样进生词本。
    • 
      
  • 也可以点「有道 / 必应」跳转在线词典网页；🔊 发音用有道语音，播放失败自动改用系统英语语音朗读。
    • 
    

    
生词本与页边生词栏

    
    
      
  • 保存生词后，当前页右侧会出现红色小标签（页边生词栏），点它能回看释义。
    • 
      
  • 右侧生词本面板：搜索、按本文档筛选、标记已掌握、编辑释义、删除、导入导出。
    • 
      
  • 「⬇ JSON」导出的文件可直接运行 D:\考研\英语\真题生词-同步墨墨.py 同步到墨墨云词本（按年份自动分章）。
    • 
    

    
数据与隐私

    
    
      
  • PDF 全程在本机浏览器内解析，不上传任何服务器。
    • 
      
  • 笔迹与生词保存在本机浏览器 localStorage，换浏览器或清理缓存会丢；请定期「导出PDF」和「⬇ JSON」。
    • 
      
  • 强推：顶部「⋯ → ⬇ 备份全部数据」可把笔迹+生词+偏好打包成一个 JSON 文件；换设备或清缓存后用「⬆ 恢复备份」一键找回。
    • 
    

    
常见问题

    
    
      
  • 双击铅笔没反应？两下间隔要短、位置要近；也可直接点工具栏切换。
    • 
      
  • 书写时有延迟 / 笔迹不够跟手？现在写字的每一帧只重画一次，且已落库的笔迹会被缓存成一张底图，写的字数再多也不会越写越卡；笔迹也不再是一段一段套上去的"糖葫芦"，而是沿线连续变宽的墨带。若仍觉得迟滞，多半是页面还没渲染完（等一下）或缩放开得太大，点缩放标签切「适宽」试试。
    • 
      
  • 扫描版 PDF 没有文本层，无法点选查词（可用「＋ 添加」手动记生词）。
    • 
      
  • 建议双击「启动网站.bat」通过本地服务访问；直接双击本文件也能用。
    • 
      
  • 键盘快捷键：1~4 切工具，Ctrl+Z 撤销，Ctrl+Y 重做，←→ 翻页。
